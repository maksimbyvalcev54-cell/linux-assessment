

## 🔎 Проверка окружения

Перед началом выполнения заданий убедитесь, что Linux-окружение работает.

Выполните:

```bash
whoami

Затем:

cat /etc/os-release

И:

pwd

Если все команды выполнились без ошибок и вы получили результат, окружение готово.

После этого переходите к Заданию 1.
```
## 📋 Правила выполнения

- Все задания выполняются **последовательно**.
- Все команды выполняйте в терминале Codespace.
- Если в задании указано сохранить результат в файл, результат должен находиться **именно в указанном файле**.
- Не удаляйте и не изменяйте файлы репозитория, если это прямо не указано в задании.
- Не устанавливайте дополнительные программы без необходимости.
- Если команда не сработала, самостоятельно определите причину ошибки и исправьте её.
- После выполнения всех заданий проверьте созданные файлы и результаты команд.
